An advanced, automated, and interactive stress-testing tool written in Python. Designed for educational purposes, security analysis, and testing network resilience under load.

> This software is created **strictly for educational purposes** and self-hosted stress testing. The author is not responsible for any misuse or damage caused by this program. Use only on your own networks or with explicit prior permission!

---

## ✨ Features

* **5 Different Attack Protocols:** Support for TCP, UDP, HTTP GET requests, and ICMP Ping.
* **Fully Automated Environment:** Automatically checks and installs missing dependencies (such as `requests` and `tqdm`) upon launch.
* **Beginner-Friendly CLI Interface:** Despite being a command-line tool, it features an interactive menu, fire-gradient visual banners, and real-time progress bars.
* **Built-in IP/VPN Checker:** Easily verify your public IP address and VPN status right from the app before running tests.
* **Multithreading Support:** High-performance execution using concurrent thread pools.
* **Open source!
